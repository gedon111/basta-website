Law of Sines and Its Application

Works for any triangle, not just right triangles. The ratio of a side to the sine of its opposite angle is the same for all three sides.

Formulaa / sin A = b / sin B = c / sin C
Worked example

In △ABC, A = 40°, B = 60°, a = 8. Find b.

b = a·sin B / sin A = 8·sin 60° / sin 40° = 8(0.8660)/(0.6428) ≈ 10.78

Practice
1. A = 50°, C = 70°, c = 12. Find a.

a = c·sin A / sin C = 12·sin 50° / sin 70° = 12(0.7660)/(0.9397) ≈ 9.78

2. B = 35°, b = 10, C = 80°. Find angle A and side c.

A = 180° − 35° − 80° = 65°

c = b·sin C / sin B = 10·sin 80° / sin 35° = 10(0.9848)/(0.5736) ≈ 17.17

The Four Cases of Oblique Triangle Problems

Which law you use depends on which parts of the triangle you're given.

CaseGivenMethod
1Two angles, any side (AAS or ASA)Law of Sines — one solution
2Two sides, angle opposite one of them (SSA)Law of Sines — the "ambiguous case": 0, 1, or 2 solutions
3Two sides, included angle (SAS)Law of Cosines — one solution
4Three sides (SSS)Law of Cosines — one solution (check triangle inequality first)

SSA rule of thumb: with angle A and sides a, b, let h = b·sin A. If a < h, no triangle. If a = h, one right triangle. If h < a < b, two triangles. If a ≥ b, one triangle.

Practice — identify the case and number of solutions
a. A = 110°, a = 15, b = 10

SSA. A is obtuse, and a > b, so exactly one solution.

b. a = 9, b = 6, C = 40°

SAS → Law of Cosines. Exactly one triangle exists.

c. a = 5, b = 5, c = 9

SSS. Check: 5 + 5 = 10 > 9 ✓ valid triangle → Law of Cosines, one triangle.

d. A = 30°, a = 5, b = 9

SSA. h = b·sin A = 9(0.5) = 4.5. Since h < a < b (4.5 < 5 < 9), there are two solutions (ambiguous case).

Solving Problems Involving Oblique Triangles
Problem 1 — Law of Sines

From point A, the angle of elevation to the top of a tree is 28°. From point B, 40 m farther from the tree along the same line, the angle of elevation is 19°. Find the tree's height.

Angle at the tree top, T: 28° − 19° = 9°. Angle at B (interior) = 19°. Angle at A (interior) = 180° − 28° = 152°.

BT = AB·sin(152°)/sin(9°) = 40(0.4695)/(0.1564) ≈ 120.1

Height h = BT·sin(19°) = 120.1(0.3256) ≈ 39.1 m

Problem 2 — Law of Cosines

Two ships leave port together. Ship A sails N50°E at 18 knots; Ship B sails S70°E at 24 knots. How far apart are they after 3 hours?

Distances: A = 54 nmi, B = 72 nmi. Bearings from north: 50° and 110°, so the angle between paths = 60°.

d² = 54² + 72² − 2(54)(72)cos 60° = 2916 + 5184 − 3888 = 4212

d = √4212 ≈ 64.9 nautical miles

Law of Cosines

Use when you have SAS (to find the third side) or SSS (to find any angle).

Side formc² = a² + b² − 2ab cos C
Angle formcos C = (a² + b² − c²) / (2ab)
Worked example — SAS

a = 7, b = 10, C = 48°. Find c.

c² = 49 + 100 − 140 cos 48° = 149 − 93.68 = 55.32 → c ≈ 7.44

Worked example — SSS

a = 8, b = 9, c = 10. Find angle C.

cos C = (64 + 81 − 100)/144 = 0.3125 → C ≈ 71.8°

Practice
1. a = 15, b = 20, C = 110°. Find c.

c² = 225 + 400 − 600cos110° = 625 + 205.2 = 830.2 → c ≈ 28.81

2. a = 6, b = 7, c = 9. Find angle B.

cos B = (36 + 81 − 49)/108 = 0.6296 → B ≈ 51.0°

The Coordinate Plane
  • Ordered pair (x, y): x tells the horizontal position (abscissa), y tells the vertical position (ordinate).
  • x-axis / y-axis: the horizontal and vertical number lines that meet at the origin (0, 0).
  • Quadrants: QI (+,+), QII (−,+), QIII (−,−), QIV (+,−). A point sitting on an axis belongs to no quadrant.
  • René Descartes: the 17th-century French mathematician and philosopher credited with inventing this system — hence "Cartesian plane" — linking algebra to geometry.
Practice — name the quadrant (or axis)
(−3, 5), (4, −2), (−6, −6), (0, 7)

(−3, 5) → QII   (4, −2) → QIV   (−6, −6) → QIII   (0, 7) → on the y-axis, no quadrant

Quadratic Inequalities in One Variable
  1. Write the inequality compared to 0.
  2. Solve the related equation by factoring to get the critical values.
  3. Plot the critical values on a number line to form intervals.
  4. Test one value from each interval in the original inequality.
  5. Write the solution set — include boundary points for ≤ / ≥, exclude them for < / >.
Worked example

Solve x² − x − 6 > 0

Factor: (x − 3)(x + 2) > 0 → critical values x = −2, 3

Test x = −3: (−6)(−1) = 6 > 0 ✓   Test x = 0: (−3)(2) = −6, fails   Test x = 4: (1)(6) = 6 > 0 ✓

Solution: x < −2 or x > 3

Practice
1. x² + 2x − 15 ≤ 0

(x + 5)(x − 3) ≤ 0 → critical values −5, 3

Test the middle interval (x = 0): (5)(−3) = −15 ≤ 0 ✓

Solution: −5 ≤ x ≤ 3

2. x² − 4x ≥ 0

x(x − 4) ≥ 0 → critical values 0, 4

Solution: x ≤ 0 or x ≥ 4

Quadratic Inequalities in Two Variables (Parabola)
  • Graph the boundary y = ax² + bx + c. Use a dashed curve for < or >, a solid curve for ≤ or ≥.
  • Pick a test point not on the curve (the origin is easiest, if it's not on the parabola).
  • If the test point satisfies the inequality, shade the region containing it. If not, shade the other region.
Worked example

y ≤ x² − 2x − 3 (opens upward, vertex at (1, −4)). Boundary is solid.

Test (0, 0): is 0 ≤ 0 − 0 − 3? → 0 ≤ −3 is false.

Since the test point fails, shade the region not containing (0, 0) — the area below the curve.

Practice — determine boundary type and which side to shade
1. y > x² + 4x + 3

Dashed boundary (strict). Test (0,0): 0 > 3 is false → shade above the curve.

2. y ≥ −x² + 1

Solid boundary. Test (0,0): 0 ≥ 1 is false → shade the region above the curve (toward the vertex side).

Absolute Value Equations
Rule|expr| = k  →  expr = k or expr = −k  (only if k ≥ 0; if k < 0, no solution)
Worked example

|2x − 3| = 7 → 2x − 3 = 7 or 2x − 3 = −7

Solutions: x = 5 or x = −2

Practice
1. |4x + 1| = 9

x = 2 or x = −2.5

2. |x − 5| + 3 = 10

|x − 5| = 7 → x = 12 or x = −2

3. |3x − 2| = −4

No solution — absolute value can never be negative.

Solving Absolute Value Inequalities
"Less than" (a > 0)|x| < a  →  −a < x < a  (and)
"Greater than" (a > 0)|x| > a  →  x < −a or x > a  (or)

Same idea for ≤ / ≥, just include the boundary. If a < 0: |expr| < a has no solution; |expr| > a is all real numbers.

Worked examples

|3x + 1| ≤ 5 → −5 ≤ 3x + 1 ≤ 5 → −2 ≤ x ≤ 4/3

|2x − 4| > 6 → 2x − 4 < −6 or 2x − 4 > 6 → x < −1 or x > 5

Practice
1. |x + 2| < 6

−8 < x < 4

2. |5 − 2x| ≥ 3

x ≤ 1 or x ≥ 4

3. |4x| + 2 > 10

|4x| > 8 → x > 2 or x < −2
